# Job Scheduling & Queue Visualization Studio

A web-based application for creating jobs, managing job queues, and visualizing job scheduling processes.

## Project Overview

This project aims to provide an interactive platform to understand and visualize job scheduling and queue management.

## Tech Stack

- React.js
- Vite
- JavaScript
- HTML
- CSS

## Current Features

- Job Creation Form
- Job Configuration UI
- Employer Details Section
- Responsive User Interface
